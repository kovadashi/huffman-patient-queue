# Patient Triage Queue Simulator

A C++ course project that simulates patient triage in an emergency department using a custom inverse Huffman tree data structure.

## Features
- Patient queue simulation
- Custom tree data structure
- Comparison benchmarks with `std::priority_queue`
- Synthetic dataset containing 18,000 records

## Files
- `Triage.cpp` — source code
- `synthetic_medical_triage.csv` — synthetic dataset
- `course_work_report.pdf` — course project report

## Technologies
- C++
- Data structures and algorithms
- Differential equations
- CSV data processing

## Project type
University coursework.
